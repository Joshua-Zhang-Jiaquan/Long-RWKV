A static, non-unpickling inspection of the hash-bound `model.pt` shows its first object is `collections.OrderedDict`; the hash-bound trainer saved `model.state_dict()`, which has that representation. PyTorch's reviewed weights-only unpickler explicitly reconstructs `OrderedDict`, so all eight ranks deterministically raise `checkpoint_payload_not_flat_mapping`. Replace the exact-type test with an appropriate mapping contract and add an OrderedDict regression test before refreshing every affected hash.
2. **P0 actual defect — runtime hardware proof is broader than the authorization.** `is_authorized_h100()` accepts every H100 with at least 79,000 MiB. An independent CPU call showed a synthetic `NVIDIA H100 NVL` with 95,830 MiB returns `True`, although authorization is specifically H100 SXM 80 GB. Manifest hashing/preflight and aggregation are unbounded, leaving at most 270 unreserved seconds if torchrun reaches its bound. The scheduler's 1,800-second cap still protects the four-GPU-hour authorization, but it may kill the job before aggregate/launcher terminal evidence is written. If an independent scheduler/registry source supplies the actual digest, bind that observation; otherwise record image identity explicitly as unknown/requested-tag-only.
